## Plexus Common Utilities

A collection of various utility classes to ease working with strings, files, command lines, XML and more.

This is the `3.x` maintenance line. It requires Java 8 or later, and still bundles the XML classes (in
`org.codehaus.plexus.util.xml` and `org.codehaus.plexus.util.xml.pull`) that `plexus-utils` 4 moved to a separate
[`plexus-xml`](https://github.com/codehaus-plexus/plexus-xml) library. See the
[README](https://github.com/codehaus-plexus/plexus-utils/tree/plexus-utils-3.x#readme) for when to use it. The
[Javadoc](./apidocs/index.html) is the reference for the classes.
